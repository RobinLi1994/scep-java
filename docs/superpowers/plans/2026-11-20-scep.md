# Java SCEP Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 按任务执行；当前空目录直接交付源码，不提交或推送 Git。

**Goal:** 可运行的 Spring Boot SCEP 工程，含协议测试、客户端和中文说明。

**Architecture:** BC 负责密码协议，服务层负责授权与签发，Spring MVC 仅处理传输。CA 显式初始化，文件存储适用于单实例。

**Tech Stack:** Java 17、Spring Boot 4.0.x、Bouncy Castle 1.87、Maven、JUnit。

**Spec:** `docs/superpowers/specs/2026-11-20-scep-design.md`

## Global Constraints

- 所有服务仅公布已经实现的 SCEP 能力。
- 使用真实签名、加密和 CSR 测试；生产代码不得绕过验签。
- 不覆盖 CA 或客户端私钥；输出中文运行说明。

## Review Focus

- CSR 与签名证书不一致、签名损坏、弱密钥。
- 续期伪造身份、改变 subject/SAN、过早续期。
- 重启丢失 CA、重复初始化覆盖密钥。
- HTTP Base64 中的加号、输入过大、缺少 operation。
- 响应的错误 CA、nonce 或 transactionID。
